Capture. Edit. Replay.

byteplay is a multi-platform network packet analyzer and replayer. Capture raw TCP/UDP traffic, mutate it byte-by-byte, and replay it against your own services to test server resilience — all from a clean native desktop app.

Features

Everything you need to probe your services

A full round-trip workflow: capture, inspect, modify, replay, and fuzz.

01

Live packet capture

Raw-socket capture with a virtualized packet list, BPF-style filtering, and per-minute statistics. 50k-packet ring buffer keeps the UI instant.

02

Byte-level hex editing

Dual-pane hex/ASCII viewer with a visual diff between your original and modified packets. Every byte accounted for.

03

Raw TCP/UDP replay

Resend captured or edited packets to any host:port. Protocol-agnostic — works below the application layer.

04

Mutation fuzzing

Deterministic, seeded fuzzer that mutates payloads and replays them with live progress and a cancel button. Bounded and safe.

05

Replay sequences

Chain packets into scripted session replays with per-step delays and timeouts — ideal for repeatable testing.

06

Packet library

Save, tag, and organize packets in a local SQLite library with full replay history and PCAP/JSON export.

Security & Ethics

Built to be responsible by default

Packet crafting is powerful. byteplay keeps the guardrails on until you explicitly take them off.

  • DEFAULT Replay and fuzzing targets are restricted to localhost and private network ranges (RFC 1918).
  • OPT-IN External targets require an explicit Allow external checkbox, per session.
  • LOCAL 100% local-first. All data lives in a local SQLite database — zero telemetry, zero cloud.
  • AUDITED Every replay is logged locally with timestamp, target, and payload hash.
  • ETHICS MIT license: for use only against systems you own or have explicit authorization to test.
